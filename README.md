# Ingro DFM – Digital Factory Model

## Overview

`Ingro DFM` is a **modular Python library** that implements the quantitative assessment of technological viability for shaft‑type parts in Siemens NX / КОМПАС‑3D.  The core follows the specifications from the project description and the normative standards:

- **ГОСТ 14.205‑83** – calculation of the technological level `Ут`.
- **Минтруд № 6 от 21.01.2000** – inter‑industry time norms.

The library provides:

1. **Data cards** (`core/cards.py`) – digitised tables of normative time cards.
2. **Engine** (`core/engine.py`) – primitive calculations (`card_time`, `compute_K_part`, `compute_T_pz`).
3. **Model** (`core/model.py`) – high‑level API returning:
   - `Nvr` – total labour time (minutes).
   - `Ut` – technological level (dimensionless).
   - `warnings` – DFM‑rule violations (from `core/recommendations.py`).
   - `saved_minutes` – summed estimated time savings.
4. **CAD extractors** – stubs for NX and КОМПАС‑3D that load a JSON passport.
5. **UI editor** – a simple console utility for inspecting and patching a passport.
6. **Test suite** (`tests/`) – `unittest` based checks for all reference scenarios.

## Usage example
```python
from ingro_dfm.core.model import compute

# Minimal passport (the fields required for the stub calculations)
passport = {
    "material_key": "45",
    "variant": "V1_грубо",
    "batch_size_q": 5,
    "surfaces": [],  # optional – used by recommendations
}
result = compute(passport)
print("Nvr:", result["Nvr"])
print("Ut :", result["Ut"])
print("Warnings:")
for w in result["warnings"]:
    print(" -", w)
print("Estimated saved minutes:", result["saved_minutes"])
```
Running the snippet prints the labour time, the technological level, any DFM rule warnings, and the total estimated time saved.

## Extending the library

1. **Complete the card data** – replace placeholder values in `core/cards.py` with the exact numbers from the official tables.
2. **Implement full formulas** – extend `engine.py` to use `K_парт(q, T_шт)` lookup tables and other detailed calculations described in ГОСТ 14.205‑83.
3. **Real CAD extractors** – replace the stub functions with calls to the NX Open API or КОМПАС‑3D SDK to generate the passport JSON automatically.
4. **UI integration** – plug `ui/passport_editor.py` into the Antigravity IDE as a side‑panel widget for interactive editing.
5. **Add more tests** – for new cards, batch sizes, and edge cases.
