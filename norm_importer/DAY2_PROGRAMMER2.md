# Модуль импорта нормативов (`norm_importer`)

Утилита автоматизированного импорта, распознавания (OCR) и структурной конвертации нормативно-справочных документов трудового нормирования (сборников ОУНВ, МОУНВ ЦБНТ, заводских нормировочных карт) в унифицированный формат JSON для расчётного ядра САПР-плагина «Ингро».

---

## Структура модуля

* `norm_importer/__init__.py` — инициализация пакета.
* `norm_importer/schema.py` — контракт выходного JSON на базе Pydantic v2 (строгая проверка размерности матриц, нормализация русской локали, прочерков и числовых интервалов).
* `norm_importer/logger.py` — настройка единого логирования процесса конвертации и диагностики ошибок в консоль и лог-файл.
* `norm_importer/office_parser.py` — парсер текстовых и офисных документов (`.docx`, `.doc`, `.rtf`, `.odt`, `.txt`) с разворачиванием объединённых ячеек таблиц и выделением примечаний.
* `norm_importer/cli.py` — интерфейс командной строки (Typer) для одиночной и пакетной обработки файлов с маршрутизацией по форматам.

## Отчёт о выполнении работ: День 2 (Разработчик 2)

В рамках Дня 2 спринта выполнены устранение замечаний ревью Дня 1 и разработка парсера офисных и текстовых форматов.

### 1. Устранение замечаний по итогам проверки Дня 1
* **Строгая валидация интервалов в `schema.py`:** парсинг диапазонов переведён на регулярное выражение с поддержкой отрицательных чисел (строка `"-2--1"` корректно преобразуется в `[-2.0, -1.0]` без потери знаков). Добавлена проверка монотонности границ (`low <= high`, обратные интервалы отклоняются с `ValidationError`) и контроль длины диапазона (ровно 2 границы).
* **Исключение перезаписи файлов в пакетном режиме `cli.py`:** при пакетной конвертации директории выходные JSON-файлы сохраняют структуру подпапок и включают суффикс исходного расширения (например, `karta_pdf.json` и `karta_xlsx.json`), что полностью исключает коллизии при совпадении имён исходных файлов.
* **Фиксация общих зависимостей:** библиотеки `pydantic>=2.0.0`, `typer>=0.12.0` и `python-docx>=1.1.0` добавлены в общий файл зависимостей проекта `requirements-normdoc2json.txt`.
* **Интеграция с маршрутизатором форматов:** в `cli.py` подключено определение типа входного документа через модуль `normdoc2json.format_router` (с безопасным fallback по расширению файла).

### 2. Реализация парсера офисных и текстовых документов (`office_parser.py`)
* **Поддерживаемые форматы:** прямой разбор `.docx` через `python-docx`, чтение `.txt` с автоопределением кодировки (`UTF-8`, `UTF-8-SIG`, `CP1251`) и разбором таблиц с разделителями `|` / табуляцией, а также автоматическая конвертация устаревших `.doc`, `.rtf` и `.odt` через `LibreOffice headless` (с текстовым fallback при отсутствии LibreOffice в системе).
* **Разворачивание объединённых ячеек (Merged Cells):** реализовано преобразование многоуровневых шапок и объединённых по горизонтали/вертикали ячеек таблиц Word в прямоугольную двумерную матрицу с автоматическим отделением заголовков от строк данных.
* **Извлечение метаданных и примечаний:** реализовано выделение заголовка карты (`Карта №...`), типа технологической операции, расчётной формулы и блока текстовых примечаний под таблицей с генерацией структурированных правил `NoteCoefficientRule` (условие срабатывания и числовой коэффициент).

### 3. Модульное тестирование (`pytest`)
* Расширен набор тестов `tests/test_norm_importer_schema.py` (проверка отрицательных диапазонов `-2--1` и отклонения некорректных интервалов).
* Обновлён набор тестов `tests/test_norm_importer_cli.py` (проверка отсутствия перезаписи одноимённых файлов в пакетном режиме).
* Добавлен новый набор тестов `tests/test_norm_importer_office.py` для проверки парсинга `.docx` с объединёнными шапками и примечаниями, а также текстовых таблиц `.txt`.

## Установка зависимостей

```bash
python -m pip install -r requirements-normdoc2json.txt
```

## Запуск утилиты (CLI)

Конвертация одиночного файла:
```bash
python -m norm_importer.cli --input path/to/karta_04.docx --output path/to/karta_04.json
```

Пакетная конвертация директории в строгом режиме:
```bash
python -m norm_importer.cli -i path/to/docs_dir -o path/to/out_dir --ocr-lang rus+eng --strict
```

## Запуск unit-тестов

```bash
python -m pytest -v tests/test_norm_importer_schema.py tests/test_norm_importer_cli.py tests/test_norm_importer_office.py
```
