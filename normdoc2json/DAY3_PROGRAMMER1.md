# День 3 программист 1

## API и контракт

`from normdoc2json import extract_pdf`
`result = extract_pdf(path)`

PDFExtraction содержит source_file, source_format (значение Format Router), pages,
warnings и requires_manual_review. PDFPage содержит page_number, kind, tables и
blocks (строки текста вне найденных таблиц). Текст примечаний сохраняется без
семантического разбора. Связь примечания с картой определяет программист 2.

PDFTable содержит values, cell_bboxes, bbox, merged_ranges, method.
Координаты — пункты PDF, начало сверху слева, система извлечения PyMuPDF
(неповёрнутая страница). Номера страниц и индексы диапазонов объединений — от 1,
границы диапазонов включительные. values — прямоугольная сетка исходных строк;
пустоты представлены пустой строкой или None. Числовая нормализация не выполняется.
Значение объединённой ячейки распространяется на её диапазон; bbox объединения
повторяется в покрытых позициях. Для borderless bbox — границы текста, а не
доказанные границы ячейки; отсутствующая ячейка имеет bbox=None.

## Реализация

Таблицы с линиями: PyMuPDF find_tables, lines_strict, use_layout=False.
Отключение layout необходимо: на контрольной сетке установленная версия
добавляла столбцы и искажала десятичные запятые.
Без линий поддерживаются простые таблицы с минимум тремя строками,
повторяющимися x-позициями, разрывами между словами более 20 pt и расстоянием
между строками до 50 pt. Это эвристика, всегда требует ручной проверки.
Сложные многострочные ячейки без границ не заявлены поддержанными.
Если на странице найдены таблицы с линиями, поиск без линий не запускается.
Смешанные типы таблиц на одной странице требуют дальнейшей доработки.

Пустые страницы, отсутствие таблиц, растровое содержимое и ошибки страниц
дают предупреждения. Обработка следующих страниц продолжается.
Защищённый/повреждённый документ вызывает InspectionError.
OCR и склейка таблиц через границы страниц не реализованы.

Проверка интерфейса выполняет grid_mapper из локального Git-объекта ветки
программиста 2, не копируя его код в продуктивный модуль. Оба PDF дают
rows_range=[6,12], cols_range=[15,30], values_matrix=[[0.28,null],[0,0.88]].
TableGrid проходит сериализацию и повторную валидацию JSON.
На текущей машине измерено около 0.028 и 0.016 с на синтетический PDF.
Это не оценка производительности на нормативных сборниках.

## Открытая приёмка

Контрольные документы синтетические. Два реальных нормативных PDF ещё нужны
для проверки точности, сложных шапок, скорости и полноты извлечения.
Полный NormDocDocument и CLI-маршрут PDF не подключены: проверен именно
контракт передачи сетки преобразователю программиста 2.
Интерфейс технически проверен, но не согласован с коллегой лично.
Общий третий день не следует считать полностью принятым до этих проверок.
