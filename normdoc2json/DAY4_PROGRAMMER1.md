# День 4 — программист 1: предобработка графики

## Выполнено

- `image_io.py`: потоковое чтение JPEG/JPG, PNG, BMP, WEBP и всех кадров TIFF/TIF;
  ориентация EXIF, прозрачность на белом фоне, доступные значения DPI.
- `preprocessing.py`: OpenCV, оценка наклона по линиям, коррекция ±15° с расширением
  холста, масштабирование по известным DPI к 300 или выше, мягкая двусторонняя
  фильтрация и адаптивная бинаризация. Морфологическое удаление мелких компонентов
  не применяется, чтобы не уничтожать запятые и тонкие штрихи.
- Потоковая передача страниц, диагностика ошибок и неоднозначностей,
  `requires_manual_review`, ограничение площади обработки с запасом под поворот.
- OpenCV подключается лениво через публичный API; версия зафиксирована:
  `opencv-python-headless==5.1.0.95`.

## Использование и контракт передачи на день 5

```python
from PIL import Image
from normdoc2json import iter_preprocessed_images

for page in iter_preprocessed_images('scan.tiff', target_dpi=300):
    if page.image is not None:
        Image.fromarray(page.image).save(f'page-{page.page_number}.png')
    print(page.page_number, page.warnings, page.requires_manual_review)
```

`iter_image_pages` выдаёт `ImagePage`: source_file, page_number от 1,
RGB uint8 image, dpi или None, warnings. Ошибка открытия даёт InspectionError.
Ошибку отдельного читаемого кадра представляет запись image=None.
Генератор следует исчерпать или закрыть, чтобы освободить файл.

`iter_preprocessed_images` выдаёт `PreparedPage`: source_file, page_number,
image (двумерный uint8, 0/255, или None при пропуске), rotation_degrees (угол
поворота OpenCV), scale (по X и Y), warnings. `requires_manual_review` вычисляется
по наличию предупреждений. Координаты результата — пиксели после EXIF,
масштабирования и поворота с расширением холста; напрямую использовать исходные
координаты нельзя. Список предупреждений нужно переносить в диагностику конвейера.

При неизвестном DPI размер сохраняется с предупреждением. Лимит по умолчанию
40 млн пикселей с запасом под поворот: превышение пропускает страницу, не обрезает
её. Лимит не заменяет ограничения декодирования Pillow и не гарантирует общий
предел потребления памяти. Не собирайте все страницы большого документа в список.
