## Интерфейс для программиста 2

```python
from normdoc2json import inspect_file, InspectionError

result = inspect_file("document.pdf")
print(result.source_format, result.page_kinds, result.warnings)
```

`inspect_file` принимает путь к одному файлу и возвращает `Inspection`. Ошибки чтения, повреждения и неподдерживаемые форматы представлены исключением `InspectionError`. Результат содержит путь, формат, MIME, кодировку текста, число страниц, типы страниц PDF, доступный DPI изображения и предупреждения.

PDF классифицируется как `pdf_text`, `pdf_scanned`, `pdf_hybrid` или `pdf_unknown`. Пустая страница получает `pdf_empty`. Наличие текста и изображения на странице считается признаком гибридного PDF, включая страницы с логотипами. Это предварительный выбор обработчика, качество текстового слоя проверяется на этапе извлечения. DPI может отсутствовать, кодировка текста определяется эвристически.

Офисные контейнеры распознаются по внутренней структуре, старые DOC/XLS — по потокам OLE. Полноту содержимого проверяет последующий парсер. Проверки в `tests/test_format_router.py` создают небольшие синтетические образцы и проверяют маршрутизацию. Для оценки точности OCR нужны реальные сканы и фотографии из контрольного набора.

`Inspection` — внутренний результат маршрутизатора. Итоговый контракт конвертации задаётся Приложением А и содержит `schema_version`, `source_metadata`, `cards`. Преобразование результатов извлечения в этот контракт ещё предстоит реализовать.

## Требования к готовой утилите

По разделу 4.2 требуется обработка PDF, DOCX/DOC/RTF/ODT/TXT, XLSX/XLS/CSV/ODS, JPEG/JPG/PNG/BMP/WEBP и TIFF/TIF. По пункту 4.3.5 CLI должна принимать файл или каталог через `--input`/`-i` и `--output`/`-o`, поддерживать `--ocr-lang` (по умолчанию `rus+eng`), `--strict` с ненулевым кодом при нераспознанных ячейках и `--debug-images`. Команды полной конвертации появятся вместе с реализацией CLI и обработчиков.

К сдаче по разделам 7–8 нужны инструкция по OCR и системным зависимостям, файл зависимостей в предусмотренном ТЗ формате, `JSON_SCHEMA_SPEC.md`, сгенерированная JSON Schema и примеры CLI для всех форматов в корневом README. Приёмка включает валидацию всех выходных JSON, точность числовых ячеек от 98% на структурированных документах и от 85% на сканах/фото, а также импорт в расчётное ядро.
